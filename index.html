STRATEGY

NotebookLM

제공된 마케팅 트렌드 PDF를 학습시켜 '우리 브랜드가 공략해야 할 니치마켓'과 '핵심 소구점'을 도출하세요.

Copy Prompt

업로드한 마케팅 보고서를 기반으로, [분야] 시장의 타겟 고객이 느끼는 고질적인 Pain Point 3가지를 정리하고, 이를 해결할 브랜드 슬로건을 제안해줘.

VISUAL

Mixboard

노트북LM이 정해준 전략 키워드를 입력하여 브랜드의 컬러와 분위기를 결정하고 무드보드를 만드세요.

실습 미션

  • 메인 컨셉 키워드 3개 입력
  • 생성된 무드보드 캡처 (갤러리 저장)
  • 제안된 메인 컬러 HEX 코드 메모
